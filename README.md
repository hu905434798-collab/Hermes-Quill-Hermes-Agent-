# Hermes Quill — Hermes Agent 安卓客户端（v2.0.0 正式版）

<!-- 项目演示视频/主截图插入位置：将 mp4 或 gif 拖入此处即可自动生成嵌入代码 -->

Hermes Quill 是专为自部署 **Hermes Agent** 打造的安卓客户端，运行在 NAS、个人主机、私有服务器上的 Hermes 都可以使用。

本软件仅作为远程控制客户端，AI 推理全部在你自己的硬件完成，App 内部不内置任何大模型。

---

## 开发初衷

这个项目最初只是为满足我个人使用需求。

之前我将 Hermes 接入 QQ、微信进行使用，虽然上手简单，但存在诸多痛点：多会话被合并在同一个对话窗口，造成 AI 记忆混乱，上下文持续膨胀；社交平台对消息格式存在限制，表格、代码块等内容展示可读性差；定时任务推送还会受到平台频率限制。

我四处寻找现成安卓客户端，官方并未推出移动端。第三方客户端两极分化，要么功能堆砌过度臃肿，要么关键能力缺失过于简陋，没有可以满足我全部需求的成品。于是我决定从零开发这款 App。

项目前后消耗 50 亿 Token 资源，历经数百个版本迭代打磨，最终形成现在版本。对比同类第三方客户端，界面简洁克制，常用功能完整保留，最大程度还原 PC 端 Hermes 操作体验；安装包体积小巧，内存占用低，并且针对后台运行做耗电专项优化。

## 核心原则

- 无广告、无埋点统计 SDK、不需要注册账号
- 对话数据仅在你的手机与私有 Hermes 服务端之间传输
- APK 体积精简，后台耗电优化，适合长期后台驻留

## 主要功能

### 1. 多设备与多 Profile 支持

单台手机可以连接多套 Hermes 服务，不同设备之间会话、收藏数据完全隔离；无缝切换服务端 Profile，切换不同 Agent 人格与工作流。

添加设备支持三种方式：**手动填写**、**扫码添加**（让 Hermes 生成连接二维码，扫一扫或从相册选图）、**粘贴配置文本**（把 Hermes 给出的配置文字复制后一键粘贴，不方便扫码时使用）。

### 2. 完整对话体验

流式输出渲染，完整 Markdown 解析，支持表格、代码块、图片。

双模式搜索：全局跨会话检索、当前会话内搜索；消息时间轴抽屉，长对话快速跳转历史记录。

长按消息菜单：编辑重发、收藏、引用，**单条消息导出 Word 为免费功能**。

拍照、图片、文件（文本 / Word / Excel / PPT）均可直接发送。

### 3. 原生问卷卡片支持

Hermes 澄清问卷直接在聊天气泡内渲染，支持多选、自定义输入、跳过题目；App 切后台、旋转屏幕自动保存草稿，避免重复提交。

### 4. Bot 与 Bot 群聊（特色功能）

Bot 列表由服务端接口动态获取，无需更新 App 即可新增角色。

在服务端定义多个独立人设 Bot，支持 Bot 群聊模式，主控 Bot 调度多个 AI 协同完成任务，适合头脑风暴、方案评审、文案共创。

### 5. App 内直接管理服务端

- **任务页**：查看定时 cron 任务、执行日志、手动触发任务、接收任务状态通知
- **模型页**：查看服务商余额，自定义模型调用优先级，聊天内快速切换模型，免费 / 限免模型有明确标识
- **技能页**：查看已部署的 Hermes 技能工具集（只读）
- **通知**：新消息弹窗、通知栏快捷回复、定时任务结果提醒

### 6. 底部导航栏（v2.0.0 新增）

屏幕底部提供 5 个页面入口：会话 / 任务 / 模型 / 技能 / 设置，点按图标或左右滑动都能切换，当前页面高亮显示，新手一眼看清 App 有几个页面。

导航栏显示方式可在「设置 → 外观 → 底部导航栏」中切换：全显示 / 仅聊天页面隐藏 / 全隐藏（默认全显示）。打字时导航栏会自动收起，不会遮挡输入框。

### 7. 功能许愿池（v2.0.0 新增）

在「设置 → 关于 → 功能许愿池」提交你希望增加的功能，也可以给别人的需求点赞。语义相似的需求会**自动合并成一条**，页面按热度（点赞 + 提及次数）排序，作者优先实现热度高的功能。

这是把开发方向交给你来定的入口——想要什么，直接说。

### 8. 界面外观

浅色 / 真暗色 / 跟随系统主题，6 套主题配色；悬浮宠物为 Pro 专属功能；导航栏显示方式可自定义。

## v2.0.0 更新亮点（从 v1.9.73 起）

**连接与稳定性**

- 连接失败自动重试一次，并给出明确原因（网络不可达 / 连接被重置 / 端口不通 / 密钥错误等）
- 诊断页新增分步检查：网络 → 域名解析 → 端口连通 → 服务健康 → 接口鉴权，一键定位卡在哪一步
- 修复拍照闪退（此前点击拍照会直接崩溃）
- 消息状态提示优化：网络中断时不再误报「AI 正在思考」，明确显示等待时长，长任务不再被误判为卡死
- 修复断线恢复把历史旧回复误当新结果的问题
- 修复手动切换模型不生效的问题

**界面与体验**

- 新增底部导航栏，5 个页面一目了然；「配置」更名为「设置」
- 新用户首次打开时，聊天页提供「添加设备」和「使用说明」快捷入口
- 扫码添加设备新增「粘贴配置文本」，不方便扫码时一贴即连
- 消息来源角标：手机 / 电脑 / QQ / 微信等平台一眼分辨
- 长消息中的链接可直接点击跳转
- DeepSeek 等模型价格表随官方调价同步更新

## 快速上手

### 1. 开启服务端 API

修改 Hermes 服务端 `.env` 配置开启 API 服务：

```
API_SERVER_ENABLED=true
API_SERVER_HOST=0.0.0.0
API_SERVER_KEY=<自定义你的密钥>
```

修改完成重启 Hermes 网关服务。

### 2. App 内添加设备

安装 Hermes Quill APK，进入 `设置 → 添加设备`，三种方式任选：

**方式一：手动填写**

- 设备名称
- 服务端地址：`http://你的服务器IP:8642`
- API 密钥：上面设置的 `API_SERVER_KEY`

**方式二：扫码添加**

在添加设备页点「扫码添加设备」，复制页面上的提示词发给你的 Hermes，它会读取自身配置并生成一张连接二维码；用相机扫一扫，或把二维码图片保存到相册后选图，自动填好表单。

**方式三：粘贴配置文本**

让 Hermes 把配置文字（一段 JSON）直接发给你，复制后在添加设备页点「粘贴配置文本」，一贴即填，不需要扫码。

### 3. 连接测试

保存并测试连接，状态显示在线即可开始对话。

> **校验方式**：手机浏览器访问 `http://<服务器IP>:8642/health`，返回 `{"status":"ok"}` 代表 API 服务正常。
>
> ⚠️ **安全警告**：不要直接把 8642 端口暴露公网，外网访问请使用 Tailscale / frp 等内网穿透工具，务必设置高强度 API 密钥。
